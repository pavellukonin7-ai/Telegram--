# Multimodal AI Telegram Bot (OpenAI & Anthropic)

Мультимодальный Telegram-бот, разработанный на Python с использованием асинхронного фреймворка `aiogram 3.x`. Бот интегрируется с ProxyAPI и предоставляет единый интерфейс для работы с ведущими языковыми моделями (GPT-4o, Claude 3.5 Sonnet, Claude Opus), а также поддерживает генерацию изображений (DALL-E 3) и синтез речи (TTS).

## Особенности проекта
- **Мультимодальность**: Переключение "на лету" между обычной моделью, рассуждающими моделями (reasoning), генерацией картинок и преобразованием текста в речь.
- **Динамический роутинг API**: Автоматическое переключение `base_url` в зависимости от выбранного провайдера (OpenAI-compatible или Anthropic REST API).
- **Асинхронность**: Использование `httpx.AsyncClient` и `AsyncOpenAI` для неблокирующей обработки запросов пользователей.
- **Обход блокировок**: Настроена поддержка SOCKS5-прокси (`aiohttp-socks`) для взаимодействия с серверами Telegram.
- **Управление контекстом**: Автоматическое сохранение и управление историей диалогов (контекстом) для каждого пользователя индивидуально.

## Технологии
- **Язык**: Python 3.10+
- **Фреймворк**: aiogram 3.x
- **API**: OpenAI Python SDK, ProxyAPI (Anthropic REST, OpenAI Compatible API)
- **Сеть**: aiohttp, httpx

## Установка и запуск

1. Клонируйте репозиторий:
```bash
git clone https://github.com/твое_имя/proxyapi-telegram-bot.git
cd proxyapi-telegram-bot
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Создайте файл `.env` в корневой директории проекта и добавьте ваши ключи:
```env
PROXYAPI_API_KEY=your_proxyapi_key_here
TELEGRAM_BOT_TOKEN=your_telegram_bot_token_here
```

4. Запустите бота:
```bash
python bot/telegram_bot.py
```

## Использование
После запуска отправьте команду `/start` в Telegram. Используйте нижнюю Reply-кнопку «Старт» для вызова главного Inline-меню. Выберите нужную модель (например, Claude Sonnet 4.5) и отправьте текстовый запрос.

## Архитектурные решения
Для работы с моделями Anthropic через OpenAI-совместимый шлюз реализован кастомный форматтер запросов, преобразующий стандартный строковый `content` в массив блоков `[{"type": "text", "text": "..."}]`, что обеспечивает строгую валидацию JSON-схемы на стороне сервера.
